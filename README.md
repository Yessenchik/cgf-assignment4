## Build and Run

### 1. Clone the repository

```bash
git clone https://github.com/Yessenchik/cgf-assignment4.git
cd cgf-assignment4
```

### 2. Configure the project

```bash
cmake -S . -B build -G Xcode
```

### 3. Build the project

```bash
cmake --build build --config Debug
```

### 4. Run Part 1 — Bézier Patch

```bash
./build/Debug/part1
```
