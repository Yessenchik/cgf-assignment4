## Build and Run

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd assignment4
```

### 2. Configure the project

```bash
cmake -S . -B build -G Xcode
```

### 3. Build the project

```bash
cmake --build build --config Debug
```

### 4. Run Part 1 — Bézier Patch

```bash
./build/Debug/part1
```
